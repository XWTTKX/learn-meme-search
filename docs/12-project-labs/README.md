# 12 · 三阶段实战与六周安排

## 实战A：可解释基线

运行标准库demo；逐步替换文字标签；手算一个BM25排序与RRF排序。产出：字段文档、错误分析、评测脚本。完成标准是能解释每个返回结果。

## 实战B：真实图文检索

准备有使用权的图片与标注；跑可选Chinese-CLIP脚本；补向量缓存；对比BM25、CLIP、融合。产出：冻结测试集、模型版本、消融表、20个bad case。至少保留一个没有改善的实验，解释原因。

## 实战C：只选一个深入点

三选一：困难负例微调、ANN精度延迟权衡、OCR与语义融合。不要同时做十个模型而没有可信评价。资源不足时优先融合与评测，模型训练放后。

| 周 | 搜索项目 | 与推荐项目共享的知识 |
|---|---|---|
| 1 | 基础、源码、文字基线 | Recall/NDCG与数据划分 |
| 2 | 图片与标注、零样本CLIP | 向量、负采样 |
| 3 | 融合消融、bad case | 多路召回 |
| 4 | 一个深入实验 | 排序与目标一致性 |
| 5 | 缓存、压测与复现 | 离在线一致性 |
| 6 | 简历、模拟面试 | 取舍与失败复盘 |

此表建议两个项目合计每周10–15小时；已有基础可压缩，没有GPU不影响第一阶段。验收以产物为准，不以读完章节数为准。
