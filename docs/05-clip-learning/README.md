# 05 · CLIP：一句中文怎样在图库里找到一张图

> 本章先只用二维向量手算检索，再读同一批图文的训练矩阵。前两节可以直接复制运行；真正的图像编码需要安装模型，并准备有权使用的图片。本仓库未报告真实图库上的模型效果。

## 5.1 从一道词法回答不了的题开始

查「累成狗」，希望找到一个趴在桌上的打工人，而图里既没有「累」，也没有狗。无论 BM25 改什么参数，只要文本词表没有连接，就不会得分。图文检索提供另一种联系：用图像编码器将画面变成一个向量，用文本编码器将「很疲惫」变成一个向量，比较它们在共同空间里的方向。

```text
查“累成狗”                 图库中的实际内容
     │                             │
文本 tokenizer                图像预处理 (RGB / resize / normalize)
     │                             │
文本编码器 + 投影             图像编码器 + 投影
     │                             │
一条 D 维向量                  N 条 D 维向量
     └───────── 归一化内积 ────────┘
                       │
                N 个相关性代理分
```

**维度一样不等于可以对比。** 两个随机初始化的编码器同样能输出 512 维向量，但没有配对训练时，没有理由让表示“疲惫”的文字和疲惫画面靠近。CLIP 学的是配对；它没有为图库中任意用户意图显式学一个「相关／不相关」的决策规则。网络梗、反讽、图中文字和动图时序都可能超出预训练覆盖。

## 5.2 第一次手算：内积与余弦给出不同名次

给定查询 q=(1,0)，图 A=(2,2)，图 B=(1,0)，图 C=(-1,0)。直接内积为 A=2、B=1、C=−1，A 排第一；归一后 A≈.7071、B=1、C=−1，B 排第一。前者偏向较大范数的 A，后者重视方向与 q 的一致。

```python
from math import sqrt

def norm(vector):
    size = sqrt(sum(value * value for value in vector))
    if not size:
        raise ValueError("zero vector does not have a direction")
    return [value / size for value in vector]

def dot(left, right):
    return sum(a * b for a, b in zip(left, right))

query = (1, 0)
bank = {"A": (2, 2), "B": (1, 0), "C": (-1, 0)}
print("dot:", [(name, dot(query, vector)) for name, vector in bank.items()])
print("cos:", [(name, round(dot(norm(query), norm(vector)), 4)) for name, vector in bank.items()])
```

余弦数值不是「有 .7 概率相关」。它是对当前模型、输入和候选库的比较。若所有候选虽不相关但都角度接近，高分也可能出现。要做空结果阈值，需要带无答案查询的验证集，按误返回与误拦截选择，不能从理论范围直接拍个阈值。

批量查询的矩阵形状为 B×D，图库为 N×D。`Q @ bank.T` 返回 B×N。一个常见错位是只交换图库向量行顺序，没有更新随行保存的图片 ID，所有数字都看着合理却返回错图。用同一图的已知行、保存的稳定 ID 和自相似做最小检查。把模型、预处理与索引版本绑定，看 [第 09 章](../09-vector-index/README.md)。

## 5.3 第二次手算：从两对图文找到 loss 的每个数

训练批中已知对角线匹配。先不关心编码器怎么得到向量，只看给定相似度：

| 图到文 | 文 A：累了 | 文 B：猫咪受惊 | 配对 |
|---|---:|---:|---|
| 图 A：趴桌 | 0.8 | 0.2 | 文 A |
| 图 B：猫 | 0.4 | 0.6 | 文 B |

令温度 τ=.2，除以 τ 后得到：

```text
                文 A   文 B
图 A logits      4      1    这一行回答：“A 图最像哪条文本？”
图 B logits      2      3
                 │      │
                 └──────┴── 每一列回答：“这条文本最像哪张图？”
```

### 5.3.1 按行选文字

对图 A，正确文 A 的概率为 exp(4)/(exp(4)+exp(1))，约 .95257；取负对数得 .04859。对图 B，正确文 B 的概率 exp(3)/(exp(2)+exp(3))≈.73106，损失 .31326。两个样本平均约 .18092。最大项大于其他项并不意味着损失为零，间隔越大才能越接近零。

### 5.3.2 转置以后按列选图

文 A 的两个候选分数为 [4,2]；文 B 的候选为 [1,3]。正确项均比错误项高 2，两个损失都是 ln(1+exp(-2))≈.12693。两方向平均约 .15393。

方向为何需要两个？设另一个矩阵为 [[.8,.2],[.85,.9]]。逐行看每张图都选对文本；逐列看第一列却选择了第二张错误图片。双向训练明确对两种竞争都施加要求。具体大规模实现会处理跨设备收集向量、样本数和正例索引；阅读源码先验证本地行列逻辑，再看分布式。

### 5.3.3 用稳定的 logsumexp 验证

```python
from math import exp, log

def loss_for_row(row, correct_index):
    peak = max(row)
    return peak + log(sum(exp(value - peak) for value in row)) - row[correct_index]

def symmetric(matrix, tau):
    scores = [[value / tau for value in row] for row in matrix]
    row_loss = sum(loss_for_row(row, i) for i, row in enumerate(scores)) / len(scores)
    col_loss = sum(loss_for_row(col, i) for i, col in enumerate(zip(*scores))) / len(scores)
    return tuple(round(value, 5) for value in (row_loss, col_loss, .5 * (row_loss + col_loss)))

good = [[.8, .2], [.4, .6]]
wrong = [[.8, .2], [.6, .4]]
for tau in (.2, .05):
    print(tau, symmetric(good, tau), symmetric(wrong, tau))
```

减去行的最大值可避免大正值 exp 溢出；如果不加回它，算的不再是原 logits 的 logsumexp。温度变小，高低分差会被放大；正确项本来领先时损失下降，错误项领先时惩罚增加。训练时也可用可学习的正缩放 exp(s) 表示 1/τ。推理同一查询、同一图库中乘以同一个正数不改变名次，但会改变数值阈值，不能沿用训练概率阈值。

## 5.4 难负例为什么既有用又危险

用图 A「趴桌疲惫」配文字「累了」。容易的负例可能是「吃草的羊」，模型已经能区分，很难提供新信息。难负例可能是「我准备继续加班」：画面相似、语用不一样，模型若混淆可以学到东西。假负例是另一种「没力气了」文字，原训练文件未配上，但对这张图实际适用。若因为没配同一行就算负例，训练将迫使合理的同义表达分开。

一行 softmax 的导数为 p−y。错项 p 越大，越会被下压，所以排在前面的假负例尤其有害。实战先从训练池取高分候选，经人工或可靠同义规则判定，再决定标注为负、正或不确定。不要拿测试查询挖训练负例；不要因一个模板同时存在两个相关版本，就把它们随机拆到训练和测试。

| 现象 | 最可能的误因 | 说明改动 |
|---|---|---|
| 同义句被推远 | 批内把未配对的正例当负例 | 同义分组或多正例掩码 |
| 基本画面能找，反义描述分不开 | 难负例覆盖少或不看字幕 | 加人工审查语用反例、OCR 路 |
| 大批量效果更差 | 假负例、分布改变或优化设置 | 固定验证集，记录碰撞与采样 |
| 图像相近却回错 ID | 版本映射错位 | 先核对张量与清单，不先微调 |
| GIF 没搜到关键动作 | 首帧没有信息 | 对比关键帧、多帧池化与成本 |

## 5.5 从论文读到一段可执行的最小图文路

先读 [CLIP 论文](https://arxiv.org/abs/2103.00020) 的配对目标，再看 [Chinese CLIP](https://arxiv.org/abs/2211.01335) 中文语料与模型说明。[本仓库推理入口](../../scripts/clip_search.py) 使用预训练模型，加载图片与文字后分别归一化，不训练任何层。把代码读成三段：输入变张量、张量变向量、向量变名次。再转到 [安装与样例](../06-quickstart/README.md)，用你自己的授权小图库一张张验证。

扩展实验按顺序做：先独立零样本评估，再接标签 / OCR / 融合，再考虑学习投影或微调。真实结果要同一图库、同一标注和 K；失效项以单条案例支持。如果没有跑推理，仅能声明已接通代码和教学例，不能把脚本存在或上游论文的数字当作自己的复现结果。
