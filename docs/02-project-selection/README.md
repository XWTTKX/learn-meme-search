# 02 · 开源项目筛选与边界

本项目选择 **Chinese-CLIP 模型 + StickerSearch 应用导读 + 自编轻量基线**。前者便于学习图文对比学习，后者让索引与查询流程可见。本仓库不是这两个项目的镜像，完整版本与许可见 [来源清单](../../SOURCES.md)。

| 候选 | 学什么 | 采用方式 |
|---|---|---|
| OFA-Sys/Chinese-CLIP | 中文图文编码、训练与推理 | 核心模型依赖 |
| oftx/StickerSearch | 本地语义搜索、索引与界面 | 阅读参考，未复制实现 |
| VEWOXIC/MEME-Indexer | 手机相册自然语言查找 | 产品交互参考 |
| meme-search/meme-search | 自托管搜索产品 | 扩展阅读，避免初期投入完整服务栈 |

StickerSearch 所查版本根目录未发现 LICENSE，不把代码重新授权后搬入自己的仓库。Chinese-CLIP 的代码许可与图片、模型权重许可分别核对。学习价值不等于 star 数；是否容易复现、能否建立相关性标注、是否能做消融更重要。

## 项目完成标准

第一档：跑通文本基线并理解指标。第二档：准备有使用权的图片，跑通图文检索并保存 bad case。第三档：独立完成一种改进，固定测试集比较效果与成本。仅完成第一档时，简历写“检索原型”，不写“已上线多模态搜索引擎”。

验收：能说出每个上游负责什么、你新增了什么、当前还缺什么。
