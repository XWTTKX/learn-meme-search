# 13 · 高频面试题与回答要点

## 三组连续追问

**面试官：BM25 既然不能理解情绪，为什么还要保留？** 用户找固定台词时，OCR 或人工配文的精确匹配可解释且便宜。「没问题」与「有问题」语义相反，向量却可能靠得近。整体指标之外，我会把精确台词单独切片，量化词法路独有命中和首位质量。

**追问：两路都给高分，直接相加不行吗？** BM25 与余弦量纲不同，前者也因查询长度变化。先用 RRF 避免拟合尺度，但它忽视第一名与第二名相差多少。积累标注后再考虑学习融合权重或保留明确台词命中，并对比固定预算下的指标和延迟。

**追问：向量索引换成 HNSW，Recall 掉了怎么办？** 同批模型向量用精确索引对照，如果近似 TopK 与精确差异很大先查 ef、距离、归一化；若两者很接近而业务正例少，查模型或数据分布。如果连精确检索结果截图和 ID 都不对应，先查版本和映射。

**面试官：离线满分为什么不能写简历？** 样例是为了验证接口故意构造，不能代表真实场景。可用结果是我完成了可复跑的评测、能计算多正例与无正例例子，并用分意图的独立集合验证策略；最后一句只有做完独立验证才说。

1. **为什么用双编码器？** 图片向量可离线预计算，查询只编码一次；代价是图文细粒度交互有限。交叉编码器适合小候选重排，不能低成本全库两两推理。
2. **为什么归一化？** 去掉向量模长对点积的影响，使检索匹配余弦目标。若训练刻意使用模长表达信息，应评估归一化带来的变化。
3. **CLIP为什么不擅长所有梗？** 预训练数据分布与表情包语境不一致，文字渲染、反讽、圈层知识可能缺失。
4. **负样本越难越好吗？** 过难且标注错误的负例会伤害训练。先去假负例，再控制难度与比例。
5. **为什么RRF？** 通道分数尺度不同，名次融合简单稳健；缺点是无法利用绝对置信差距。
6. **怎么证明改动有效？** 同数据划分、候选库、预处理和评测口径，只改变一个变量；报告分桶、区间与失败案例。
7. **离线好线上差怎么办？** 检查流量分布、真实意图、延迟、去重、展示策略与指标代理偏差；离线相关性不等于实际发送率。
8. **百万图库如何扩展？** 分开处理编码缓存、索引选择、更新机制与服务并发，并用精确检索校验ANN损失。
9. **一个query有多个正确结果怎么办？** 标注集合，使用Recall/NDCG；不只算首个命中。
10. **你写了什么？** 指向自己的基线、数据适配、指标和实验记录；模型与上游应用明确归属。

练习方式：先用90秒回答，再接受“给公式、给反例、给实验”三轮追问。回答到未做过的部分，明确说出实现计划与缺少证据。
