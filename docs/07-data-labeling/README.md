# 07 · 数据准备、标注与防泄漏

先建立图片清单，记录来源、使用范围和文件哈希。优先使用自己创作或明确授权的图片。聊天截图可能包含个人信息，不能直接放入公开仓库。

## 相关性规范

| 等级 | 判定 | 例子 |
|---|---|---|
| 2 | 可直接表达查询意图 | “不想上班”对应疲惫打工情绪 |
| 1 | 部分相关但不够贴切 | 同样疲惫但语境是运动 |
| 0 | 不相关或含义相反 | 开心期待上班 |

当前评测脚本使用二值相关性。若使用上述等级，另实现 graded NDCG，增益设为 `2^rel-1`，不能直接套本仓库二值公式后声称分级评测。

建议起步 500–2,000 张图片、100–200 条查询，数字是工作量建议，不是已收集规模。标注时合并词法与向量召回结果形成候选池，补随机样本，减少只偏向单一路模型的评价。每条查询尽量有两人独立标注并讨论分歧。

切分按语义意图与图片模板分组；同一模板换字图不能跨训练与测试泄漏。验证集调参数，测试集最终只评一次。未标注不等于不相关，报告标注覆盖范围。

验收：提交不含私有图片的字段说明、查询分组规则和脱敏的分歧案例。数据资产本体放 `data/private/`，默认忽略。
